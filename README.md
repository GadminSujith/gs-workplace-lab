# Workplace Automation Lab

Hi, I’m Sujith. I’m an IT professional who enjoys finding simpler ways
to get things done through automation.

Over the years, I’ve built scripts and workflows to reduce manual work,
solve recurring problems, and make life easier for IT teams. This
repository is where I share that work, along with new ideas and projects
as I develop them.

## What you’ll find here

- PowerShell scripts for everyday IT tasks
- Windows deployment and device-management tools
- Azure Logic Apps and workflow automation
- Examples, documentation, and lessons from practical experience

Each project has its own README with its purpose, setup instructions,
and requirements.

## Using these projects

You’re welcome to explore the projects and adapt them to your environment,
subject to the repository’s license.

Read the project instructions and test changes in a suitable environment
before using them in production. Some projects require your own Azure,
Microsoft Entra, or Intune configuration.

## About this repository

This is a personal collection, maintained independently. The projects
reflect my own experience and interests and are not official products
or statements from any employer or vendor.
